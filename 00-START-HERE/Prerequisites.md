## 1. Knowledge Prerequisites

**Zero programming background chalega.** Ye course literally "What is JavaScript" se shuru hota hai.

Agar tumne pehle kisi bhi language mein thoda bhi code likha hai (Python, Java, C, etc.), to shuruaati modules (01-04) tumhe fast lagenge — lekin unhe skip mat karo, JavaScript ke apne quirks hain.

## 3. Mindset Prerequisites (Sabse Important)

- **Consistency > Intensity.** 1 hour daily, 3 months, better than 8 hour Sunday cram.
- **Comfortable with confusion.** JavaScript ke kuch parts (closures, `this`, event loop) pehli baar mein confusing lagte hain — ye normal hai, dusri baar clearer hota hai.
- **Typing code khud** — copy-paste se muscle memory aur debugging skill nahi banti.
- **Mistakes se darna nahi** — errors padhna aur samajhna ek core skill hai, is course mein "Common Mistakes" section har jagah is liye hai.

---

## 4. What You Do NOT Need

- ❌ Computer Science degree
- ❌ Math background (beyond basic arithmetic and logic)
- ❌ Prior web development experience
- ❌ Paid tools/subscriptions (sab tools is course mein free hain)
