## Is Module Mein Kya Hai?

Ye tumhara **starting point** hai. Yahan code likhna shuru karne se pehle hum ye samajhenge ki JavaScript hai kya, browser ke andar wo chalti kaise hai, aur tumhare computer pe use run karne ka setup kya hota hai.

Bahut log is module ko "boring theory" samajh ke skip kar dete hain — **mat karna**. Jab aage closures aur event loop aayega, tab "JavaScript kaise run hoti hai" ka ye foundation hi tumhe bachayega.

## Yahan Log Sabse Zyada Confuse Hote Hain

- **"JavaScript aur Java same hain?"** — Bilkul nahi. Naam ki similarity ek 1995 ki marketing decision thi, aur kuch nahi.
- **Semicolons optional hain?** — Technically haan (ASI ki wajah se), lekin kuch specific cases mein ASI galat jagah semicolon daal deta hai. Chapter 06 mein ye trap detail mein hai.
- **Setup pe atak jaana** — Agar VS Code install karne mein time lag raha hai, temporarily browser console (F12) se hi shuru kar do. Setup perfect hone ka wait mat karo.
