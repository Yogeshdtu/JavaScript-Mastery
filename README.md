## 🗺️ Learning Path (Short Version)

```
01-04  Fundamentals      →  variables, operators, loops, if-else
05-09  Core JavaScript   →  functions, arrays, objects, closures, coercion
10     Modern JS         →  classes, prototypes, generators, Map/Set
11-12  Browser           →  DOM, events
13-15  Async             →  callbacks, Promises, async/await, Event Loop
16-17  APIs & Modules    →  HTTP, fetch, REST, ESM/CommonJS
18-20  Backend           →  Node.js, servers, databases
21-23  Quality           →  testing, performance, security
24-26  Expert            →  engine internals, design patterns, pro practices
27-30  Apply & Revise    →  projects, problems, interviews, cheat sheets
31-32  Bonus             →  TypeScript, build tools
```

Har module folder ke andar ek **`00-Module-Overview.md`** hai — usse pata chalega us module mein kya hai, kitna time lagega, aur kis order mein padhna hai.

## 📖 Har Chapter Ka Format

Har single chapter same **18-section structure** follow karta hai, taaki tumhe kabhi guess na karna pade ki information kahan milegi:

Learning Objectives → Prerequisites → Simple Hinglish Explanation → Technical Explanation → Syntax → Basic Examples → Detailed Examples → Mental Model → **What Happens Internally** → Common Mistakes → Edge Cases → Real-World Usage → Comparisons → Practice Questions → Challenge → **Interview Questions** → Summary → Revision Checklist

**Language:** Explanations Hinglish mein (jaise ek acha teacher class mein samjhata hai), saara code aur technical terms English mein.

**Labels:** ✅ = Modern/recommended approach, ⚠️ = Legacy/purana (samajhna zaroori hai, likhna nahi).

## ✅ Kaise Padhna Hai

1. **Sequence follow karo** — course deliberately layered hai, chapters ek dusre pe build karte hain.
2. **Har chapter ka "Practice Questions" aur "Challenge" section karo** — skip mat karo, wahi actual learning hai.
3. **Code khud type karo**, copy-paste mat karo.
4. **Har module ke baad** [Progress-Tracker.md](./00-START-HERE/Progress-Tracker.md) mein checkbox tick karo.
5. **Projects parallel mein karo** — theory khatam hone ka wait mat karo.

## 🎯 Is Library Ke Baad Tum

- JavaScript ko **beginner se professional level** tak samajhoge — sirf syntax nahi, "andar kya ho raha hai" bhi.
