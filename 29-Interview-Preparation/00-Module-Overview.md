## Kaise Use Karna Hai (Important)

1. **Pehle khud answer socho**, phir answer padho. Seedha answer padhne se yaad nahi rehta.
2. **Awaaz mein bolo.** Interview mein tumhe bolna hai, likhna nahi — practice bhi waise hi karo.
3. **"Why" pe focus karo.** Interviewer aksar follow-up poochta hai: "aur aisa kyun hota hai?"
4. **Mock interviews last mein karo**, timer laga ke, ek hi baithak mein.
5. Jo question galat ho, uska **chapter wapas padho** — file ke links follow karo.

---

## Top 5 Topics (Sabse Zyada Poocha Jaata Hai)

1. **Closures** — ek counter example ready rakho
2. **`this` binding** — chaaro rules aur priority
3. **Event loop** — output order trace karna
4. **`==` vs `===`** — coercion ke saath
5. **Promises vs async/await** — aur `Promise.all`
