## Why Projects Matter

Theory padhna zaroori hai, lekin **projects banana** hi tumhe actually confident developer banata hai. Har project real-world skills combine karta hai — jo tumne alag-alag modules mein seekha, ek project unhe **saath mein** use karwata hai.

**Golden rule:** Jab bhi corresponding theory-module complete karo, usi stage ka project turant try karo — [00-START-HERE/README.md](../00-START-HERE/README.md) ke "Projects Per Stage" table follow karo.

---

## How to Use This Section

Har project file mein ye structure hai:
1. **Requirements** — kya banana hai
2. **Features** — kya-kya functionality chahiye
3. **Architecture** — file-structure, data-flow
4. **Step-by-Step Build Process** — actual code, explained
5. **Debugging Tips** — common issues jo aa sakte hain
6. **Testing** — kaise verify karo sab kaam kar raha hai
7. **Improvements** — polish ke liye ideas
8. **Advanced Version** — agla-level challenge

**Approach:** Pehle khud try karo (kam se kam requirements aur features padhke, apna implementation attempt karo), phir diye gaye solution se compare karo.
